# 续跑一致性与缓存边界

续跑是**复用已提交的节点输出快照**，不是 LangGraph 持久化 checkpoint，也不是自动恢复任务。平台服务先验证执行身份，再选择安全缓存；不兼容时返回 409，不会静默改成全量执行。

## 使用方式

对同步 `/api/workflows/{id}/run` 或 SSE `/api/workflows/{id}/execute` 提交原始输入和 `resumeRunId`：

```json
{
  "input": {"topic": "原始问题"},
  "resumeRunId": "上一次失败或取消的 runId",
  "timeoutMs": 300000
}
```

只有同工作流、调用方有权访问、已结束且带一致性指纹的 FAILED / CANCELED 记录可以续跑。RUNNING、SUCCESS、缺少完成时间的记录以及升级前没有指纹的历史记录均被拒绝。越权/不存在返回 404，其他不兼容情况返回 HTTP 409 / code 4090。所有准备校验都发生在插入新运行记录之前。

收到 409 后，检查提示并自行决定是否完整重跑：完整重跑应去掉 `resumeRunId`，可能重新执行文件写入、HTTP 调用等副作用，前端不会替用户自动重试。

## 执行上下文指纹

`ExecutionPreparationService` 冻结实际请求，`ExecutionFingerprint` 当前生成 `v2:` + SHA-256 摘要，保存为 `execution_record.execution_fingerprint`。v2 纳入用户存储策略，旧 v1 记录不能续跑，需完整重跑以免复用旧共享目录引用。

纳入身份的内容：

- 工作流 ID、执行用户 ID、输入内容；
- 实际执行图的节点 ID、类型、配置，以及边与执行引擎类型；
- 递归内联的所有子工作流定义；
- 平台服务下发的服务商配置/凭据、MCP 服务配置/授权和请求 mock 选项。

JSON 对象按键递归排序，数组顺序保留。单纯修改节点位置、显示名称、边 ID、保存产生的版本计数、runId 或执行超时不改变指纹。因此可以移动画布、重保存、延长整体超时后续跑；但修改节点配置里的超时/重试策略仍会改变定义身份。

凭据仅在内存请求中参与摘要，**不保存含密钥的执行上下文快照，也不向详情接口返回指纹**。凭据轮换或其他下发配置变化会保守地使缓存失效，即使变化的是本次未实际使用的服务商。

## 缓存选择

源记录和节点日志在短的只读 REPEATABLE_READ 事务中读取，避免读取过程中删除记录造成混合快照。使用每个节点最新的日志：

1. 只考虑根图中类型一致、状态 SUCCESS 的节点；`input` 永远重新执行。
2. 失败、取消、未执行或缺少有效日志的节点，以及其依赖下游均不复用。
3. 依赖包含画布边、condition / llm_router 的配置分支、模板里的 `{{nodeId.field}}` 引用和 merge 的显式 sources。
4. 可复用成功节点的输出缺失、损坏或不是 JSON 对象时拒绝整个续跑，不混用部分损坏缓存。空对象 `{}` 是有效缓存。

这是保守策略：未走过的条件分支可能使其后合流节点缓存失效，宁可少复用，也不复用无法验证依赖的结果。

## 留痕与计量

- 新记录的 `resume_run_id` 保存直接来源，详情返回 `resumeRunId`。
- Python 缓存命中事件带 `cacheHit: true`，平台服务在节点日志、同步结果和详情中保留这个标记；执行详情页显示“复用历史输出”。
- 历史输出中的 usage 原样保留，但不重复累计为新执行的 token、成本或新 LLM token 指标。
- `agentflow.execution.resume.node.hits` 统计节点缓存命中数。

## 数据库升级

平台服务使用 SQLAlchemy 建表：本地 SQLite 文件首次启动即创建全部表；MySQL 部署也由 `Base.metadata.create_all()` 自动建表。历史数据库不在迁移范围内；升级后已有执行记录若缺少一致性指纹，会拒绝续跑并要求完整重跑。

## 尚未保证的事项

- Python 环境变量、运行时代码、知识库内容、文件、远程模型或工具行为变化，不在平台服务请求摘要覆盖范围内；需要刷新这些结果时完整重跑。
- 动态构造的变量引用或任意外部状态依赖不一定能被静态依赖分析识别。图设计应使用显式边和模板引用表达数据依赖。
- 失败节点可能已经产生部分副作用。重执行不提供 exactly-once，需要业务接口幂等键或补偿策略。
- 没有持久化任务队列、跨实例取消或自动 checkpoint 续做，仍是单实例运行语义。
