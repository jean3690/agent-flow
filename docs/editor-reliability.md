# 编辑与调试可靠性打磨

> 本文记录此前编辑器打磨阶段的验证结果。后续新增节点与最新回归结果见 [实用数据与工具节点](data-nodes.md)，当前测试总数以 README 为准。

本轮聚焦「编辑 → 保存 → 发布 / 调试」，保留原有页面风格、三端架构和已有未提交工作，没有引入新的测试依赖。

## 修复内容

### 编辑器

- 用实际保存字段与最近成功提交的快照比较“未保存”状态，覆盖工作流名称、节点配置、位置和连线；选择节点、缩放画布不会误报修改。
- 保存前冻结请求内容，同一时刻的重复保存复用请求；等待响应期间的新编辑继续保持未保存状态。保存不再将停用工作流强制改为启用。
- 调试 / 发布先确认当前草稿已保存。如果自动保存过程中又有修改，不启动旧图，也不发布过期草稿。
- 增加 Ctrl/Cmd + S，输入名称时也可使用；名称纳入撤销 / 重做，撤销前提交尚在防抖窗口内的最近修改。
- 站内离开、浏览器返回和切换工作流时提示放弃未保存修改；保存 / 发布期间暂缓离开。刷新 / 关闭使用浏览器原生 `beforeunload` 保护。
- 切换编辑器路由 ID 时重新初始化页面，避免继续编辑上一工作流；加载失败提供重试，禁止提交尚未加载的空画布。
- 去掉重复声明的 Vue Flow 默认 Shift 框选配置，避免当前依赖版本的运行时类型警告。

### 调试与执行流

- SSE 增量解析支持 LF、CRLF、CR，以及跨网络块的 UTF-8、多行 JSON、心跳和缺少末尾空行的最后事件；保留非 JSON 文本内容。
- 解析器正常结束、提前退出或异常时均取消响应体并释放 reader；收到执行终态后不再等待连接关闭。
- 流式执行与普通 REST 请求统一使用 `VITE_API_BASE_URL`，HTTP 错误提取后端消息，401 清除过期 token。
- 未收到终态就结束的连接明确标记为“中断”，提示到执行历史确认，而不是悄悄结束或残留运行中节点。
- 使用每次执行独立的取消控制器身份校验，旧请求延迟收尾不会覆盖新执行的运行状态与输出。
- 从执行记录进入编辑器续跑时，响应式读取稍后传入的 runId 和原始输入；收起后重新展开不会重复自动执行。
- 调试输入先校验为 JSON 对象，拒绝 `null`、数组和字符串；重置时清除旧续跑入口。

## 验证入口

| 命令 | 范围 | 是否需要后端 |
| --- | --- | --- |
| `make test-web` / 前端目录 `npm test` | 13 项 SSE 单元回归，无需浏览器 | 否 |
| `make test-ui` / 前端目录 `npm run test:ui` | 19 项编辑、保存竞态、发布、路由保护、执行状态与续跑浏览器回归 | 否 |
| `make check` | AI / Java / 前端单元 / 三种 SDK 测试、类型检查与构建 | 否 |
| `make e2e-ui` | 原有真实三端浏览器冒烟 | 是 |

隔离浏览器回归复用现有 Playwright，自动启动 `127.0.0.1:5175` 的 Vite 服务并在结束后停止；严格使用独立端口，所有后端接口被 mock，不连接本地数据库或真实模型。首次运行需在前端目录执行 `npx playwright install chromium`。新增入口已接入 CI，测试结果目录加入忽略规则。

## 本轮实测结果

- `make check` 通过：AI 96、Java 57、前端 SSE 13、Python SDK 12、TypeScript SDK 14、Java SDK 10，共 **202 项测试**，以及前端 / TS SDK 类型检查、前端 / Java 服务 / TS SDK 构建。
- `make test-ui` 的 **19 项 Chromium 隔离回归通过**；本轮合计新增 32 项前端测试。
- 续跑查询响应式修复后，另行重跑前端类型检查与生产构建，通过。
- 本轮没有重新运行依赖真实三端的 `make e2e-ui`，也没有进行真实模型联调或性能压测。
- Python / JDK / Mockito 的第三方依赖弃用警告仍存在，不影响测试通过。

## 边界

- 本轮没有增加离线草稿存储或崩溃后的草稿恢复；刷新提示能否展示取决于浏览器。
- 本地“停止”先中止结果接收，并在已取得 runId 时发送后端取消请求。取消是否成功、流中断后任务是否仍在运行，以执行历史的后端状态为准。
- mock 回归用于验证前端行为，不代表真实供应商、整栈部署、吞吐或生产高可用已验证。
