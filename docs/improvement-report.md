## 已完成的改进

### 1. 执行权限

- 执行列表在数据库查询中按普通用户的 userId 筛选，管理员可查询全部记录。
- 详情、取消、删除和续跑缓存读取检查记录归属，越权统一返回 404。
- 工作流下的执行列表先校验工作流访问权限；递归子工作流引用同样检查权限。
- 禁止删除仍在执行的记录，避免后台收尾写入孤立节点日志。

### 2. 生命周期与资源

- 凭据、子工作流和续跑缓存准备成功后才插入 RUNNING 记录，避免准备失败残留记录。
- 异步任务入队前登记取消句柄，排队取消后不会被新句柄覆盖或重新向 AI 服务提交。
- 任务拒绝返回 HTTP 503，并写入 FAILED 终态、完成时间和执行指标。
- 上游中断时对运行和未结束节点统一收尾；错误响应的上游 InputStream 显式关闭。
- 平台服务同步/流式执行共用独立 SSE 解析器，保留多行 JSON 和末尾事件。

### 3. SDK

- Python/TypeScript SDK 由完整响应收集改为逐行回调，增加 HTTP 错误处理、资源释放、查询参数编码和中断标记恢复。
- Python SDK 正确声明 SSE Accept、读取流式错误响应体、处理默认事件、多行 JSON、换行格式和末尾事件。
- TypeScript SDK 增量解码跨块 UTF-8 / CRLF，实现请求总期限，在退出或异常时取消响应体并释放 reader。
- 修复 TypeScript 编译目录与包入口不一致，隔离测试产物，加入 prepack 构建和明确 exports；补充锁文件及两种 SDK 本地安装文档。
- 不再假定 SDK 已发布至公共包仓库，修正 README 中变量未定义的 TypeScript 示例。

### 4. 工程验证与文档

- 新增 17 个执行权限/生命周期测试与 7 个 SSE 解析测试。
- 原有 SDK 36 个测试中，修复前 26 个失败，修复后全部通过；没有删改测试断言绕过失败。
- `make test` 纳入两种 SDK，新增 `make check`、`make test-sdk`、`make e2e-service`。
- CI 增加 Python/TypeScript SDK 真正的测试与构建，以及 TypeScript 包入口、打包清单和服务调用验证。
- 修正“完全无状态”“多实例直接扩容”“流式严格总超时”等过度描述，补充上线边界与简历材料。

## 第二阶段：续跑一致性与执行准备边界

- 将执行请求组装、递归子图收集及校验拆到 `ExecutionPreparationService`；将源记录权限、上下文与缓存依赖校验拆到 `ExecutionResumeService`，`ExecutionService` 保留生命周期、事件消费与指标职责。
- 保存版本化执行上下文 SHA-256 指纹及直接续跑来源，不保存含凭据的上下文快照；输入、实际图/子图、用户或下发配置变化时返回 409，不创建新执行记录。
- 仅支持已结束且有指纹的 FAILED / CANCELED 记录。位置、显示名、边 ID、版本计数及整体执行超时变化保持兼容；历史无指纹记录不猜测回填。
- 缓存选择排除 input、失败/未执行节点及其依赖下游，覆盖隐式分支、模板引用和 merge sources；可复用输出损坏时拒绝整个续跑。
- 空对象输出也可命中；缓存命中事件和持久化节点增加 `cacheHit`，不重复统计旧 usage 的 token/成本。执行详情显示缓存标记和 `resumeRunId` 来源。
- 数据库表结构由 SQLAlchemy 自动创建，SQLite / MySQL 使用同一套模型定义。
- README 只针对续跑能力、边界和文档链接更新相关行，保留原有其他修改。

## 第三阶段：上游期限与事件资源保护

- 增加 `ExecutionControl` 和独立期限调度器：从任务出队连接 Python 开始，固定限制响应头等待与 SSE body 消费，支持取消 pending future、关闭阻塞流和移除期限任务。
- AiClient 执行链路改用可取消异步 HTTP；迟到 body 显式释放，错误响应不读取可能永不结束的 body，取消通知不阻塞请求线程。
- 所有执行入口收到运行终态即停止读取，不等待 done / EOF；超时记 FAILED 并收尾未完成节点，增加上游超时指标。
- SSE 解析器限制无换行长行和多行事件累计大小，保留原有换行、BOM、UTF-8 和末尾事件兼容。
- 请求 timeoutMs 限制为 1–3600000ms，Python 正确支持小于一秒的运行预算；内联子图审批也会扩展有效等待预算。
- Python 事件缓冲按事件数和 UTF-8 字节数限制，预留终态/关闭位置；超限保留已接纳进度、发送明确失败并停止生产，不被节点重试或失败继续吞掉。
- 增加空闲注释心跳与 AI 准入；活动 runId 重复拒绝，名额在响应 finally 清理后释放。
- 同步 emit 保持不变，采用“超限失败”而非等待式背压。未新增数据库字段，配置已补入两端 .env.example 与 Compose。

## 第四阶段：文件用户隔离与私有预览

- 平台服务 新增 `FileService` 统一选择存储用户与权限，移除文件 GET 匿名放行；JWT / API Key 下载均走认证，浏览器伪造存储头无效。
- Python 所有文件路由与执行/取消路由需要内部令牌；用户目录只由运行时绑定，不能通过环境字段或工作流输入覆盖。
- 上传、文本读写、删除、列表与媒体产物使用 `.users/{userId}`；文件与本地图引用共用路径/符号链接检查，子工作流及 foreach 继承用户身份。存储辅助函数本身拒绝未绑定的全局 Settings，缺少用户时不回退到共享根。
- 文件 URL 增加显式用户命名空间，用户相对 path 保持兼容；模型本地参考图仅从当前用户目录转换/上传。
- 前端带 JWT 获取 Blob，凭证不进入 URL；远程媒体不接收 JWT，页面切换清理 Blob 并取消未完成下载，404 不会退回匿名加载。
- 历史共享文件保留，管理员通过显式 legacy 入口只读处理，不自动迁移或猜测归属；活动 HTML/XML/SVG/脚本类型强制附件并设置私有缓存、nosniff 与 sandbox。
- 执行指纹提升为 v2 并纳入存储策略，旧 v1 源记录需完整重跑。本阶段未增加数据库字段，第二阶段已有 MySQL 列升级要求仍适用。
- 调整文件/媒体测试夹具以显式提供用户上下文，保留原有行为断言；整栈冒烟与翻译脚本的下载请求同步携带 JWT。
