## 已完成的改进

### 1. 执行权限

- 执行列表在数据库查询中按普通用户的 userId 筛选，管理员可查询全部记录。
- 详情、取消、删除和续跑缓存读取检查记录归属，越权统一返回 404。
- 工作流下的执行列表先校验工作流访问权限；递归子工作流引用同样检查权限。
- 禁止删除仍在执行的记录，避免后台收尾写入孤立节点日志。

### 2. 生命周期与资源

- 凭据、子工作流和续跑缓存准备成功后才插入 RUNNING 记录，避免准备失败残留记录。
- 异步任务入队前登记取消句柄，排队取消后不会被新句柄覆盖或重新向 AI 服务提交。
- 任务拒绝返回 HTTP 503，并写入 FAILED 终态、完成时间和执行指标。
- 上游中断时对运行和未结束节点统一收尾；错误响应的上游 InputStream 显式关闭。
- Java 同步/流式执行共用独立 SseReader，保留多行 JSON 和末尾事件。

### 3. SDK

- Java SDK 由完整响应收集改为逐行回调，增加 HTTP 错误处理、资源释放、查询参数编码和中断标记恢复。
- Python SDK 正确声明 SSE Accept、读取流式错误响应体、处理默认事件、多行 JSON、换行格式和末尾事件。
- TypeScript SDK 增量解码跨块 UTF-8 / CRLF，实现请求总期限，在退出或异常时取消响应体并释放 reader。
- 修复 TypeScript 编译目录与包入口不一致，隔离测试产物，加入 prepack 构建和明确 exports；补充锁文件及三种 SDK 本地安装文档。
- 不再假定 SDK 已发布至公共包仓库，修正 README 中变量未定义的 TypeScript 示例。

### 4. 工程验证与文档

- 新增 17 个执行权限/生命周期测试与 7 个 SSE 解析测试。
- 原有 SDK 36 个测试中，修复前 26 个失败，修复后全部通过；没有删改测试断言绕过失败。
- `make test` 纳入三种 SDK，新增 `make check`、`make test-sdk`、`make e2e-service`。
- CI 增加 Java SDK 真正的测试与构建，以及 TypeScript 包入口、打包清单和服务调用验证。
- 修正“完全无状态”“多实例直接扩容”“流式严格总超时”等过度描述，补充上线边界与简历材料。

## 后续优先级

1. **安全闭环**：知识库/文件/模型配置细粒度授权，匿名下载改签名 URL，Webhook 限流和请求边界。
2. **状态恢复**：崩溃后执行终态修复、持久化队列、跨实例取消路由和 Cron 分布式锁。
3. **续跑一致性**：按输入与图版本进行缓存失效，评估 LangGraph 持久化 checkpoint 和幂等副作用。
4. **执行保护**：同步入口统一容量控制，严格流消费期限、心跳和事件队列背压。
5. **规模化检索**：评估真实文档集，增加检索指标、向量索引与容量压测。
6. **生产基线**：升级并验证依赖兼容性、生成覆盖率报告和真实模型回归集，再产出可用于简历的性能指标。
